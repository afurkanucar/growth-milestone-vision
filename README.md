# 👶 Growth-Milestone Vision: Pedatric AI Tracker

## 📌 Project Vision
A specialized Computer Vision tool for monitoring infant development. Specifically calibrated for milestones starting from April 2025 (Gökçe's development dataset).

## 🛠 Methodology
- **OpenCV Integration:** Automated biometric measurement from visual data.
- **WHO Standard Alignment:** Real-time comparison against World Health Organization growth curves.
- **Predictive Analytics:** Uses historical data to forecast upcoming developmental milestones.

## 📌 Project Overview
Monitoring a child's physical development is a critical task for parents and pediatricians. **Growth-Milestone Vision** utilizes advanced image processing to automate the tracking of growth metrics. By analyzing periodic photos, the system can estimate height growth and monitor motor skill progression without invasive measurements.

## 🚀 Key Technical Features
- **Biometric Landmark Detection:** Uses Mediapipe/OpenCV to identify key anatomical points for consistent measurement.
- **Growth Curve Analysis:** Compares extracted data against WHO (World Health Organization) standard growth charts.
- **Perspective Correction:** Implements algorithms to adjust for camera angle variations, ensuring accurate pixel-to-centimeter conversion.
- **Automated Milestone Logging:** Detects and timestamps significant developmental stages (e.g., first time sitting or standing) via video frame analysis.

## 🧠 The Engineering Why
This project was born out of a need for a non-invasive, data-driven approach to parenting. It combines high-level Python scripting with practical computer vision to turn everyday photos into actionable health data.
